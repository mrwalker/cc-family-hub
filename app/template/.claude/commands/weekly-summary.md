# /weekly-summary

A friendly, readable summary of the week from the last plan, for the family group chat.

Read `workspace/state/last-plan.yaml` (run `/daily-plan` first if it doesn't exist) and the
member profiles in `workspace/members/`, then write the summary yourself: the week's shape in
a sentence or two, each day's highlights, who needs to do what, and anything urgent.

If asked for one person ("just Sam's week"), keep only their events and action items.

With an Anthropic API key, `npx family-hub summary` prints one without you.
